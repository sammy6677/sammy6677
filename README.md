### 🚢 ZoeiStore – Import Order & Profit Tracker
Manages the full Alibaba → Kenya → Jumia cycle. It tracks orders through a 5-stage shipping pipeline, converts USD to KSh, and works out the true cost per piece, profit, margin and break-even price after Jumia fees. Jumia stock is linked to its import orders, and checks flag problems such as duplicate tracking numbers or loss-making prices. Access is PIN-protected with auto-lock.  
**Tech:** JavaScript · HTML · CSS · cloud database  
🔗 [Code](https://github.com/sammy6677/zoeistore-orders)
